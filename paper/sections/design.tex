\section{Study Design}
\label{sec:method}

\paragraph{Task and generator.}
The Highscore feature records a finished run's score, player name and
survival time in a file and shows the records sorted in a menu panel of
the game ApoMario. In \emph{Generation} the model sees ApoMario; in
\emph{Reuse} it also sees the sibling game ApoIcarus, which has the
feature, and is asked to reuse it. Task text, games and functional tests
are those of the prior study. Every artifact is generated by OpenAI's
\texttt{gpt-5.6-luna} through the Codex adapter at reasoning effort high;
the same model writes the security documents and acts as judge. A
\emph{cell} is a task variant with one base context (structural S,
functional F, behavioural B, alone or combined, or none); the strategy
comparison uses Generation S and Reuse S+B, five artifacts per cell.

\paragraph{Delivery.}
\emph{One response}: the protocol of the prior study, one answer, no
feedback; a response that returns an existing file whole or an edit whose
anchor does not occur is rejected (strict delivery; the baseline in
Table~\ref{tab:matrix} is also collected under a lenient rule that accepts
the whole file). \emph{Agentic}: the model may search and read the
repository and submit up to five times with compiler and test feedback,
within 24 tool turns. The \emph{judge} is the same model in a separate
conversation; it sees each pending submission with the security context
and cancels it, returning advice, when it can quote a submitted line that
violates a cited requirement or control, at most three times per
trajectory.

\paragraph{Security context.}
An acquisition agent receives the one-line task, the vocabulary above as
an output schema, and, depending on the strategy, a read-only copy of the
repository; it inspects it with shell tools under a command budget and
writes one document, whose code citations are resolved against the parsed
source (statements that cite nothing resolvable are dropped). The three
strategies: \emph{S1}, high-level guidance from the repository without
code citations; \emph{S2}, a full document with every statement anchored
to code; \emph{S3}, a generic document written without any repository.
The document is appended once after the task. The agent's instructions
(version 13 for every row of Table~\ref{tab:results}) require a bound to be
stated as a number and the domain of each validated value to be stated;
earlier versions and their effects are recorded in the study repository.

\paragraph{Evaluation.}
Sixteen functional tests from the prior study (seven unit, four
integration, five in the live game) and ten security checks
(Table~\ref{tab:mapping}) run on every artifact in an isolated JVM: the
store rejects a negative score, a negative time, a missing, blank or
over-long name (five input-policy checks); at most one hundred records
are retained; a corrupted store file does not crash the game; a 64~MiB
line and a million-record store do not exhaust memory; no Java object
deserialization is used. A check that cannot run counts as not passed.
``All pass'' in Table~\ref{tab:results} also requires the persistence
round trip, an eleventh check that a valid record survives a restart.
Tokens and model-call time are recorded per call for generator and judge.
