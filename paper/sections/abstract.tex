\begin{abstract}
\begin{itemize}
\item Question: agent-written security context before implementation;
security gains, functionality, token/time cost.
\item Setting: Highscore + harder Achievements task; Java game;
Generation / Reuse; \texttt{gpt-5.6-luna}, reasoning high;
one response / agentic delivery; ten artifacts per arm.
\item Contexts: high-level repository guidance; code-anchored document;
generic document without repository; optional cancelling judge.
\item Highscore, checks among compiled artifacts: 22\% to 82--87\%
(one response); 33\% to 87--90\% (agentic, documents without judge);
mostly high functional-test means.
\item Achievements: no one-response compilation; agentic full document,
checks 78\% to 95\%, all-pass artifacts 0/10 to 5/10.
\item Judge: higher input-token use; no mean-check improvement;
lower Achievements compilation. Limits: two tasks, one game pair,
one model, small samples.
\end{itemize}
\end{abstract}
