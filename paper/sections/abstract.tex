\begin{abstract}
Security context, typed statements on assets, trust boundaries, weakness
types, requirements and controls of a change, is appended to the prompt of a
generator implementing a Java Highscore feature by generation and reuse, with
functional feedback only; it is acquired under researcher-written security
perspectives or by an agent from a snapshot and a one-line feature
description. In rounds I07 and I09 every context arm has fewer failed issue
checks than its control under every assignment of unresolved outcomes,
without systematic functional loss; a one-sentence task-only instruction
retains most of the reduction. Agent-acquired inserts remove more failures
(to 2 and 3 of 50) but cost functional success: in 12 of 46 trajectories the
only failing tests end a run on a player without a name, which one insert
clause tells the hook to skip; without that clause the insert keeps the
effect (36 to 2 of 50) with 4 of 5 functional.
Limits: one task, one repository pair, five trajectories per arm sharing one
insert, descriptive counts, unresolved large-record checks, single-pass
review.
\end{abstract}
