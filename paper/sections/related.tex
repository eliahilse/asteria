\section{Related Work and Terms}
\label{sec:related}

\begin{itemize}
\item \emph{Weakness}: flaw type; CWE catalogue~\citep{cwe}.
\item \emph{Security requirement}: property the feature must ensure~\citep{haley2008}.
\item \emph{Control}: enforcement mechanism;
\emph{enforcement point}: where applied~\citep{nist80053}.
\item \emph{Trust boundary}: differing assumptions about received data~\citep{manadhata2011}.
\item \emph{Security context}: assets, boundaries, weaknesses,
requirements, controls; labelled statements; source-line evidence or
explicit proposals; supplied before implementation.
\item Prior security evaluation: isolated snippets /
benchmarks~\citep{pearce2022,siddiq2022,hajipour2024}; generic
secure-coding prompt wording~\citep{tony2025}.
\item Here: feature integration in an existing code base; game family
from copying and adaptation~\citep{krueger2018,dubinsky2013}.
\item Prior study\footnote{\url{https://github.com/ieiris/llm-context-generation-reuse}}:
structural, functional, behavioural context; one response per prompt;
compilation and functional tests. Retained tasks, games, tests, contexts;
added security documents and checks.
\end{itemize}
