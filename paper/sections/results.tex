\section{Results}
\label{sec:results}

Every artifact was generated by OpenAI's \texttt{gpt-5.6-luna} through the
Codex adapter at reasoning effort \emph{high}, one request per turn, no temperature
set; the same model wrote every agent document and acted as judge. Every
arm has a control collected in the same round. Table~\ref{tab:matrix} is
the baseline: the prior study's sixteen cells rerun with this generator
under its protocol. Table~\ref{tab:results} answers the question of this
paper per context strategy: does the artifact work, is it secure, and
what does it cost. Per-cell counts, unresolved outcomes and
identification bounds against each round's own control are in the
repository.

\paragraph{Functional.}
Under one response 40\% of the artifacts compile without security context
and 50 to 70\% with one; the rest are rejected at delivery (a target file
returned whole, an edit anchor that does not occur) or do not compile.
Compiled artifacts pass 93 to 100\% of the functional tests whatever the
context. With repository tools and feedback every artifact compiles and
passes 96 to 100\% of the tests, with or without a document.

\paragraph{Secure.}
Compiled artifacts without security context pass 22\% (one response) and
33\% (agentic delivery) of the ten security checks. With any of the three
documents they pass 82 to 87\% under one response and 86 to 90\% in
agentic delivery; the three strategies lie within five points of each
other, the document written without any repository included. The judge
that cancels a violating submission (at most one per trajectory, with a
verbatim quote) leaves the rate where it is and adds one artifact that
passes everything, at 1.4 times the tokens. What the compiled document
artifacts still fail is almost only the resource pair, the oversized-line
read and the million-record store: the documents bound records and names,
and the artifacts apply the byte bound after reading a line. No
one-response artifact passes every test and every check; 0 to 20\% of the
agentic ones do.

\paragraph{Usage and time.}
One response reads 0.1 M input tokens and takes 1.2 to 1.9 minutes per
artifact; a document does not add time here. An agentic trajectory reads
0.8 M without and 1.0 M with a document in about two minutes; the judge
raises that to 1.4 M and 2.7 minutes, because every submission is judged
in a second conversation. Writing a document is one agent run of one to
four minutes.
