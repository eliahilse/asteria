\paragraph{Functional: Highscore.}
\begin{itemize}
\item One response: compilation 40\% without context, 50--70\% with;
compiled-artifact functional-test means 93--100\%.
\item Agentic: compilation 100\% throughout; functional-test means 96--100\%.
\end{itemize}

\paragraph{Secure: Highscore.}
\begin{itemize}
\item Compiled-artifact checks: 22\% to 82--87\% (one response);
33\% to 87--90\% (agentic, S1--S3).
\item S1--S3 within 5 percentage points per mode;
generic document competitive despite no repository access.
\item All pass: no one-response artifacts; 0--2/10 agentic artifacts.
\item Judge versus S2: checks 87\% to 86\%; all pass 0/10 to 1/10;
$1.4\times$ input tokens; no consistent benefit across measures.
\end{itemize}

\paragraph{Usage and time: Highscore.}
\begin{itemize}
\item One response: 0.1 M input tokens; 1.2--1.9 model-call minutes/artifact.
\item Agentic: 0.8 M without context, 1.0 M with; about 2 minutes.
\item Judge: 1.4 M; 2.7 minutes.
\end{itemize}

\paragraph{The second task: Achievements.}
\begin{itemize}
\item One response: 0\% compilation in every arm; integration across
5 game classes; exact-edit failures (Table~\ref{tab:results-ach}).
\item Agentic control: 90\% compilation; 78\% checks;
point-overflow and oversized-line failures in every compiled artifact.
\item Full document: 100\% compilation; 95\% checks; 5/10 all pass,
all five in Generation; three Reuse artifacts failing functional suite.
\item S1/S3: 96\%/94\% checks, but 70\% compilation each;
3/10 all pass each. High check means alongside delivery failures.
\item Judge versus S2: compilation 100\% to 60\%; functional artifacts
4/10; all pass 5/10 to 1/10. Trajectory explanation: cancellations
consume attempts needed for five-class integration.
\item Input/time: 1.4--1.5 M, 3.4--3.7 minutes without judge;
2.0 M, 4.5 minutes with judge.
\end{itemize}
