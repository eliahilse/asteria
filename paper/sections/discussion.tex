\section{Discussion}
\label{sec:discussion}

\begin{itemize}
\item Explicit security documents: large measured gains on these tasks;
tools and feedback supporting compilable integrations.
\item Provenance: similar compiled-artifact check rates across S1--S3;
no demonstrated check-rate advantage from repository grounding here;
no general equivalence claim.
\item Functionality: mostly high test means among compiled outputs;
compilation and all-pass outcomes still varying, especially Achievements.
\item Judge: added cost; no consistent Highscore benefit;
worse Achievements delivery under fixed attempt budget.
\item Wording: three instruction revisions removing previously observed
failures; explicit numeric bounds and validation domains;
history in study repository.
\end{itemize}

\paragraph{Threats to validity.}
\begin{itemize}
\item Two tasks, one game pair, one model in all roles, ten artifacts/arm;
limited generalisation.
\item Shared acquired document within each arm: generation variability
given that document; acquisition variability unmeasured.
\item Five input-policy checks out of ten: heavy weighting;
passing this suite versus broader security.
\item Instructions revised after inspecting task failures;
adaptation to observed benchmarks; transfer unestablished.
\item Checks among compiled artifacts; compilation and all-pass rates;
conditional rates versus overall delivery success.
\end{itemize}

\section{Conclusions}
\label{sec:conclusions}

\begin{itemize}
\item Agent-written guidance before implementation: Highscore checks
22--33\% without context versus 82--90\% with documents;
agentic Achievements, full document 78\% to 95\%, all pass 0/10 to 5/10.
\item Generic guidance competitive on checks; full repository document
highest Achievements all-pass rate in this sample.
\item Judge: no consistent gains justifying added cost;
attempt budget relevant on harder task.
\item Next question: transfer to another repository.
\end{itemize}
