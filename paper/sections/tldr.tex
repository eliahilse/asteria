\section*{TL;DR}
\noindent
In rounds I07 and I09 every context arm has fewer failed issue checks than its
control, with no systematic loss of functionality. Control artifacts normalise
invalid input instead of rejecting it; insert wording maps to code. A
one-sentence task-only instruction retains most of the reduction.
Agent-acquired inserts cut failures further but cost functionality through one
clause: skip recording when the player name is unavailable; dropped, the
effect stays and functionality returns. Evidence:
one task, one repository pair, five trajectories per arm, descriptive counts.
