# I05: repair-budget sensitivity

I04 completed 69/80 trajectories with all 16 functional tests passing. Requirements
reduced detected issue checks strongly but reached full functionality in only 2/5
Reuse S+B trajectories, versus 4/5 controls. Two unsuccessful trajectories had
repeated rejected exact-text edits; another repeatedly failed lifecycle checks.
This motivates a **prospective five-submission budget**, without changing the
feature task, edit format, evaluator, model settings or security context inserts.

Run all four paper-context cells × none / overview / requirements / boundaries ×
five fresh trajectories: **80 trajectories, at most 400 code submissions**.
Each arm receives fresh controls and the same repair allowance. Complete the full
schedule regardless of direction; no selective continuation of failed I04 runs.

The six I04 security inserts and every condition's initial user prompt are reused
byte for byte. No earlier generated code or outcomes enter a new model conversation.
The system's budget wording changes from three to five submissions; remaining-budget
feedback follows that allowance. Feedback stays limited to delivery, compilation
and functional checks. Model identity must match Luna; provider settings without
attestation remain marked unverified.

Primary outcomes are full functional success within five submissions and the
per-check security outcomes on the final evaluated artifact. First-submission and
within-three success are retained. The first three submissions are not a controlled
counterfactual for I04: the larger allowance is visible from the beginning. Time and
model sampling can also affect the cross-round budget comparison.

The frozen v3 evaluation and original test contracts remain unchanged. Following
collection, apply the already frozen amplification-precondition audit to every
final compiled artifact and publish the separately qualified measurements. Both
raw and qualified reports are retained. Unresolved checks never count as passes.

Context acquisition is held fixed intentionally. This round tests delivery budget
sensitivity, not another independent sample of context generation. Statistical
reporting retains all trajectory denominators, per-test rates and marginal Wilson
intervals, plus bounds over unresolved issue counts. No significance or general
vulnerability-reduction claim follows from a favorable aggregate count.
