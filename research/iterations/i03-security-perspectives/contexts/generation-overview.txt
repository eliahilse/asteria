Task-relevant security context for adding persistent highscores to ApoMario. The game exposes the active level through the component and exposes level players; player points are mutable and level completion updates points before/around end-of-run processing. The level also exposes a remaining-time value and a passed-time calculation, but the inspected code does not establish that either is elapsed wall-clock milliseconds. Menu architecture is model/panel based and uses a navigation graph, so a dedicated highscore view must cross the existing menu navigation/rendering boundary. No remote calls or cryptographic mechanisms were observed in the inspected excerpts. Persistence is a new local file boundary supplied by the required Path constructor; its location, format, permissions, corruption handling, and atomicity remain implementation decisions and were not established by the snapshot.
