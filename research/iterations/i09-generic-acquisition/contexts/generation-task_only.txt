Security context for implementing persistent highscores and integrating them into ApoMario. The repository is indexed primarily as Java classes embedded in ApoMario.jar. Existing gameplay state exposes the player list and each player's points, while level timing is maintained as a decrementing integer. The menu and game views are coordinated by ApoMarioPanel, which constructs panels and switches to the menu. Add a dedicated highscore view, connect recording to actual run-end transitions, and use validated durable persistence.
